# Private UNREVIEWED dialogue review

For a complete original role, run `node scripts/crew-recordings/production/voice-v2/prepare-review.cjs scheduling` (replace role as needed). Failed/incomplete sources and unreconciled or mismatched ledger bindings are rejected. Presenter captions use accepted text/hash bindings and actual question start/end events. Agent text uses the final stable-ID monitor transcript, collapsing consecutive agent/user fragments into exactly four agent blocks and three question blocks; ambiguous alternation or timing fails. No ASR text or invented reply is substituted.

Output is private `voice-samples/production-v2/reviews/ROLE-draft/{preview.mp4,preview.vtt,REVIEW-DRAFT.json}`. The video mux trims the screen’s recorded lead-in, preserves full actual dialogue audio, normalizes audio and enables faststart. It is fully decoded for validation. Original media is preserved. Source/output hashes and mappings are recorded; review status remains **unreviewed**. Draft captions split readable chunks with word-weighted coarse times across observed audible spans, accounting for activity-detector onset/release delay. Timing and wording must be checked by listening. These files provide no acceptance flags and never invoke the accepted-media finalizer or publication.

Retakes require explicit `ROLE --take retake`, only concierge/sales, matched reconciled `RETAKE-ATTEMPTS.json` with fixed allowance ID `awc_autumn_owen_fresh_demos_20261011`, and separate `recordings/ROLE-retake` input / `reviews/ROLE-retake-draft` output. There is no fallback to failed originals and no retry or allowance action.

After drafts are prepared, launch `node scripts/crew-recordings/production/voice-v2/review-server.cjs` and open `http://127.0.0.1:4207/`. The loopback-only gallery exposes fixed MP4/VTT routes for the five original roles plus explicit Autumn/Owen retakes, with approved names, native player controls, default draft captions and no autoplay. Unavailable clips show pending status. No arbitrary private file, call ID, credentials or private path is exposed. Responses are noindex/no-store; robots disallows every route. Playback starts no provider call. Parent handles actual desktop/mobile listening/player QA and owner review before any accepted finalization or website selection.

Focused checks: `node --test scripts/crew-recordings/production/voice-v2/prepare-review.test.cjs scripts/crew-recordings/production/voice-v2/review-server.test.cjs`.
